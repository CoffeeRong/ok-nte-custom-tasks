# ok-nte-custom-tasks

[ok-nte](https://ok-script.com/ok-nte) 单文件自包含自定义任务合集。每个任务是一个 `.py` 文件,所需模板图以 base64 内嵌、运行时按捕获分辨率自动缩放匹配——无需额外部署 `assets/` 模板或 `LabelEnum.py`。

## 任务列表

| 文件 | 任务名 | 版本 | 适配 |
|---|---|---|---|
| [fishing_xingzhu.py](fishing_xingzhu.py) | 自动钓鱼-星渚码头 | 1.8.0 | ok-nte v1.5.9(ok_script 3.x) |

> v1.8.0 起适配 v1.5.x 新 API(`task_icon()` / `open_f1_domain()`);更早的 ok-nte 版本请改用 v1.7.1 及以前的脚本。

## 安装(二选一)

1. **复制文件**:把 `fishing_xingzhu.py` 复制到 `data\apps\ok-nte\working\ok_tasks\` 下,重启 ok-nte;
2. **编辑页粘贴**:ok-nte 任务编辑页新建脚本,粘贴文件全文并保存。

任务列表「都市闲趣」分组下出现 **自动钓鱼-星渚码头**。

## 自动钓鱼-星渚码头

在原版「自动钓鱼」零改动的基础上,增加传送寻路前置流程:

大世界任意位置 → (可选)M 开图检查右上角都市活力,为 0 直接结束
→ F1 界域页「经验及甲硬币」页签点「前往」,传送至胡迪尼的魔术舞台
→ M 开大地图(首键可能被丢弃,最多按 3 次),右上区域优先搜索传送锚点(找不到回退全屏)
→ 点击锚点偏左下位置打开传送确认面板 → 确认传送
→ 按录制路径盲走 → 点按 A 微调逼近,核对 F 提示文字含「钓鱼」(最多 10 次,超限自动停止)
→ 进入原版钓鱼流程(抛竿 / 控条 / 补饵卖鱼 / 轮次逻辑零改动)。

**任务自停四重保险**(到限自动干净停止,无需手动点停止):

| 保险 | 触发条件 |
|---|---|
| 都市活力检查 | 开图读取计数为 0(配置开关开启时) |
| 寻路失败 | 连续失败 2 次(`NAV_MAX_RETRY`) |
| 钓鱼失败轮数 | 达到 5 轮(`FAIL_LIMIT`,0=不限) |
| 任务总超时 | 默认 30 分钟(配置项,0=不限) |

**可配置项**(任务卡片上仅 2 个,其余为脚本标定区常量):

- `都市活力为0时跳过`(默认开)
- `任务总超时(分钟)`(默认 30)

**前提**:大地图缩放档位为 Mid(模板档位;游戏重开后自动回归 Mid)。

## 扩展到其他钓点

复制 `fishing_xingzhu.py` 改名,改标定区四处即可:`ANCHOR_FEATURE` / `ANCHOR_REGION` / `WAYPOINTS` / 类名与任务名;新锚点模板用 base64 内嵌替换 `ANCHOR_TEMPLATE_B64`。
